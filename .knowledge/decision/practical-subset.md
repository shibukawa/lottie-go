title: Practical Lottie Subset
---

Do not chase the full Lottie spec. Target a practical subset sufficient for editor-produced UI assets. Unsupported features are skipped explicitly and rendering continues (policy:robustness). Feature set staged via requirement:phase-p0 / requirement:phase-p1 / requirement:phase-p2; hard exclusions in policy:out-of-scope. Start P2 only on demonstrated demand.
