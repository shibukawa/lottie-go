# Opening animation sample

A game opening built as one scene file, in the style of a classic title
sequence — and of one particular woodblock print:

1. **Vanity card** (`logo` phase): a gem logo pops in over a starfield
   and fades out. Click it or press Enter to skip; otherwise the phase's
   2-second clock rolls into the opening.
2. **The great wave** (`opening` phase): a Hokusai-styled wave — free
   bezier paths whose silhouette morphs as it rises, curls into the claw,
   and collapses, shedding whitecap spray — crashes over a beige paper
   sky, then the sea settles into a calm loop (`playback.then`), Fuji on
   the horizon.
3. **Title**: as the wave clears, the sun-badge slams in (`start: 3`) and
   the "WAVE QUEST" text node lands over it.
4. **PRESS START**: a focusable text node appears (`start: 4.6`); Enter
   or a click fires the `start-game` callback, which this demo answers by
   overwriting the text via `SetText`. Esc restarts the opening.

Run it, or open it in the layout editor:

```
go run ./examples/layout/opening-animation
go run ./layout examples/layout/opening-animation/assets/opening.scene.json
```

Every asset is generated by `go run ./examples/layout/opening-animation/gen`
— authored in this repository, so there is no third-party licensing to
track. The scene references **one bundle per layer** (`logo.lottie`,
`sky.lottie`, `ocean.lottie`, `title.lottie`, `backdrop.lottie`), so
swapping the logo is replacing `logo.lottie` and nothing else — each
actor shows as its own row in the layout tool's Sources list. The text
uses the stopwatch sample's font, referenced rather than duplicated.

Setting `OPENING_SCREENSHOT=/path/out.png` (and optionally
`OPENING_SCREENSHOT_TICKS`) renders headlessly, writes that frame, and
exits — the repository's usual way to check a picture without a human at
the window.
