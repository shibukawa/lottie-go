# Searchlight assets

All `.lottie` bundles and the scene file here are generated — do not
edit by hand. Regenerate with:

```
go run ./examples/layout/searchlight/gen
```

`LuckiestGuy-Regular.ttf` is copied by that generator from the stopwatch
sample: the "Luckiest Guy" typeface by Brian J. Bonislawsky DBA
Astigmatic, distributed by
[Google Fonts](https://fonts.google.com/specimen/Luckiest+Guy) under the
Apache License 2.0 (the same license as this repository). It sits beside
the scene so the sample can embed this one directory.
