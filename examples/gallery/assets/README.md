# Sample animations

All `.json` files in this directory are from the `data/` directory of
[LottieFiles/test-files](https://github.com/LottieFiles/test-files),
which that repository dedicates to the public domain (CC0):

> Everything in ./data/ is public domain (CC0). Everything else is MIT.

File names encode the original path: `shapes-bezier.json` is
`data/shapes/bezier.json` upstream.

`shape-style-gradient-linear.json` and
`shape-modifiers-trim-simultaneously.json` were originally included to
demonstrate graceful degradation; since the P1 milestone both gradients and
trim paths render natively.
